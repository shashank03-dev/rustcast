## List of features in rustcast:

1. Application launching
1. Website opening (google search + regular websites)
1. Tray Icon
1. Clipboard history
1. Using arrow keys for selecting option
1. Easter eggs (_randomvar_, _67_ and _lemon_)
1. Opening settings file from searching
1. Jev — a plain-words command operator (`jev open downloads`, `jev record firefox`, …)
1. Screen recorder with window lock, aspect lock, minimize-proof recording and
   adding extra windows into a locked recording (`Super+Shift+R`)
1. Screenshot studio (`Super+Shift+S`): frozen-screen region / window / full-screen
   capture with a pixel magnifier, 12 annotation tools (arrow, line, rectangle,
   ellipse, pen, highlighter, text, numbered steps, pixelate/blur/solid censor,
   spotlight, colour picker, select & move), undo/redo, copy / save / save as,
   pin to screen, beautify, delayed capture, quick capture, annotate existing images
1. Copy text from screen — OCR (`Super+Shift+T`) with translate, search and QR codes
