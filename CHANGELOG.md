# Changelog

All notable changes to RustCast are listed here.
Versions follow semantic versioning.

## [0.7.2] - 2026-10-06

The first public release.

### Added

- **Launcher** with app, file, maths, unit conversion, emoji and web search, grouped
  into sections and ranked by use.
- **Jev**, a plain-words command operator: open, find, create, launch, close, tile,
  capture and record, including several steps in one sentence.
- **Screenshot studio**: frozen-screen capture of an area, window or screen with a pixel
  magnifier, 12 annotation tools, undo/redo, pin to screen, beautify, delayed and quick
  capture, and a draggable floating thumbnail.
- **Copy text from screen (OCR)** as text, code or a table, with smart actions for links,
  emails, phone numbers, colours, sums and QR codes, plus translate and search.
- **Colour palette** from any area and **before/after compare** for screenshots.
- **Screen recorder** that locks onto one window, keeps recording when it is minimised or
  on another workspace, accepts extra windows mid-recording and never records RustCast.
- **Clipboard history** for text and images, persisted to disk.
- Tray menu with quick actions, GNOME shortcut registration, autostart, and install /
  uninstall scripts.
- Prebuilt x86_64 Linux release with checksum.
